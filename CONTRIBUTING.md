# Участие в разработке GROWLIVO

Спасибо за интерес к проекту! Здесь находятся исходники Roblox-игры на Luau. Основной язык общения — **русский**.

## Перед изменениями

- Для ошибок и предложений используй [Issues](https://github.com/Zeihos/GROWLIVO/issues).
- Для изменений кода создай отдельную ветку и Pull Request.
- Не добавляй в репозиторий ZIP-архивы сборок, временные файлы, токены и личные данные.
- Не меняй имя `GROWLIVO_Profiles_v1` или версию схемы профилей без продуманного плана миграции.

## Как вносить изменения

1. Изменяй игровые скрипты в `src/`.
2. После правок обнови автономный установщик:
   ~~~bash
   python3 tools/sync_installer.py --write
   ~~~
3. Проверь соответствие:
   ~~~bash
   python3 tools/check_installer.py
   python3 tools/sync_installer.py --check
   ~~~
4. Если изменился игровой процесс, проверь результат **в Roblox Studio**, включая Output.
5. В описании PR укажи, что изменилось, что проверено и есть ли риск для сохранений.

**Важно:** Python-проверки контролируют совпадение файлов, но не запускают Luau и не заменяют игровые тесты.

## Открытый доступ и использование

Код можно просматривать в публичном репозитории. Отдельная лицензия пока не опубликована, поэтому вопросы повторного использования или распространения следует предварительно согласовывать с владельцем проекта.
