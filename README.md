# GROWLIVO

**GROWLIVO** — многопользовательская Roblox-игра в жанре Clicker Simulator.

**Текущая версия:** Alpha 0.9.26 · **Статус:** разработка и игровое тестирование

## Возможности

- Клики, улучшения силы клика, перерождения и кристаллы.
- Три мира: Sky Crown, Crystal Vale и Aurora Grove.
- Яйца, питомцы, экипировка, сортировка инвентаря и слияние питомцев.
- Ежедневные сундуки, задания, достижения, событие «Звёздный дождь» и испытания рун.
- Автокликер, доступный после двух перерождений, и комбо ручных кликов.
- Таблицы лидеров, интерфейсы для компьютеров и телефонов, панель администратора.
- Сохранение профилей Roblox DataStore с защитой от конфликтующих сессий.

## Запуск в Roblox Studio

1. Создайте резервную копию существующего place или откройте отдельный тестовый place.
2. Убедитесь, что **Play остановлен** (режим Edit).
3. Откройте [`installer/INSTALLER_CommandBar.lua`](installer/INSTALLER_CommandBar.lua).
4. Скопируйте **всё содержимое файла** в Command Bar Roblox Studio и выполните.
5. Запустите Play, проверьте Output и основные игровые механики.

Установщик создаёт/обновляет Roblox Script, LocalScript и ModuleScript в нужных сервисах, сохраняет существующие числовые `AdminUserIds` и пытается откатить изменения при ошибке записи исходников. При обновлении **сначала делайте резервную копию**.

### Сохранения

- Для неопубликованного Studio-place используется **временное хранилище**, очищающееся после Stop.
- Для проверки реального DataStore опубликуйте **отдельную тестовую игру** и включите Studio Access to API Services в настройках безопасности.
- Не проверяйте новые системы записи данных на боевых профилях.
- Текущий DataStore: `GROWLIVO_Profiles_v1`; версия схемы профиля: `7`.

## Работа с исходниками

`src/` — основной источник игрового кода. В автономный установщик встроена копия каждого скрипта. При изменении исходников необходимо синхронно обновлять соответствующую запись внутри `installer/INSTALLER_CommandBar.lua`.

Проверка соответствия:

```bash
python3 tools/check_installer.py
```

Та же проверка запускается через GitHub Actions. Она проверяет структуру и совпадение исходников, **но не заменяет запуск и тестирование в Roblox Studio**.

## Версии и старые сборки

В основном дереве хранится только актуальная версия исходников. Ранее загруженные архивы Alpha 0.9.15 и 0.9.16 удалены из текущей ветки как устаревшие дубликаты; их можно найти в [истории коммитов](https://github.com/Zeihos/GROWLIVO/commits/main/).

Текущий релиз остаётся **Alpha**, поэтому перед публикацией игры необходимы ручные проверки мультиплеера, сохранений, UI на разных экранах и производительности.
